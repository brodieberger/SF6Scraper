# SF6Scraper
(Future) Open source web application for scraping and displaying Street Fighter 6 profile data from streetfighter.com/6/buckler/.

As of right now, this project is very unfinished. But you can try running it yourself, which you will need to add a Capcom account email address and password, as the information on https://www.streetfighter.com/buckler cannot be accessed without an account linked to the game.

Alternatively, you can access a demo at https://www.brodieberger.com/streetfighter/. The scraper is currently offline, but some accounts are still saved. As an example, you can try the following ID: 1711733433
